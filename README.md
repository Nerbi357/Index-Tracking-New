# Sparse Index Tracking — S&P 500

Учебно-исследовательский проект: строим портфель из небольшого числа акций, который
повторяет динамику индекса S&P 500 (sparse index tracking), и честно оцениваем, насколько
хорошо он отслеживает индекс и сколько стоит его вести.

Подробности - в `SPEC.md` (спецификация) и `tasks/plan.md` (план работ).

## Структура

- `src/index_tracking/` - код: данные, методы, бэктест, метрики, визуализация
- `notebooks/` - тетради: `01_data`, `02_modeling`, `03_analysis`, `04_report`
- `data/`, `results/`, `reports/` - экспорт данных, результатов, отчет и фигуры
- `tests/` - тесты (`pytest`)
- `.claude/` - служебные скиллы и заметки (удаляемы в конце проекта)

## Установка

    pip install -e ".[dev,notebook]"

## Данные

Недельные цены качаются с Yahoo Finance тонким клиентом на `requests`. Готовый снапшот
коммитится в `data/snapshot/` для воспроизводимости.

## Соглашения

Все наши функции помечены префиксом `custom_` (классы - `Custom`): в тетради сразу видно,
где наш код (для дебага - в `src/index_tracking/`), а где вызовы библиотек.
